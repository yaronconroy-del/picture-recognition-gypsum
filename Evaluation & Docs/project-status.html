Project phases

1. Data collection
Photos captured and sorted by hand
 Done

  • Manually sorted into 5 classes: valid day/night, invalid day/night, empty filter
  • Filenames randomized (img_<id>.jpeg) with a manifest back to the originals — no ordering that leaks the label
2. Project setup
Repo, docs, and dataset tooling in place
 Done

  • Project pushed to a private GitHub repo, under version control
  • A reusable script for adding new photos to the dataset consistently
